MRIDUL TIWARI PORTFOLIO — QUICK START

1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html. The website opens in your browser.
4. To edit the text, right-click index.html and open with Notepad or VS Code.
5. Your photo is already included as profile.webp. Keep it in the same folder as index.html.
6. Your college, branch and email have been filled in. Your GitHub profile link is set. Add your LinkedIn profile link if you have one.
7. The resume button currently downloads a sample editable TXT resume; update its details in script.js.
8. The contact form opens the visitor's email app. It does not send messages through a server.

TO SHOW AT COLLEGE
